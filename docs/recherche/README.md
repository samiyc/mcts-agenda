# Les recherches sur les emplois du temps

Sami (6/11/2026) : le cadrage, comme la cuisine : le modèle, la règle à battre, un prompt de recherche métier, un
glossaire et les questions. Ce dossier rassemble ce que disent les sources publiées et ce qu'elles ne disent pas.

À lire dans cet ordre :

1. [`../modele.md`](../modele.md) : le modèle, les règles simples, les mesures, les bancs publics, ce qu'on prend de
   la lib ;
2. [sources.md](sources.md) : chaque chiffre, sa source et jusqu'où elle a été lue, puis les calculs de cadrage ;
3. [glossaire.md](glossaire.md) : les mots de l'établissement et de la recherche, et leur nom dans le code ;
4. [questions.md](questions.md) : ce qui reste à trancher, pour Sami et pour un principal adjoint ou un CPE, chaque
   fois avec une recommandation ;
5. [prompt.md](prompt.md) : le prompt d'une recherche qui viserait ce qu'on n'a pas trouvé.

**La règle.** Un chiffre a sa source, ou il est écrit comme une hypothèse avec sa question. Un chiffre lu seulement
dans un résumé le dit, et se relit avant de décider quoi que ce soit. La recherche du 6/11 a lu dans le texte les
arrêtés de 2017 et de 2023 sur les grilles, les résultats d'ITC 2011 et le rapport de DTU sur ITC 2019 ; le reste
vient de résumés : le site du ministère et Légifrance ont refusé l'outil de lecture, et itc2019.org ne s'affiche pas
sans JavaScript.
